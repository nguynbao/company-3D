# Image Enhancer & Studio Optical Polish Module (Integrated in DESIGN & VIDEO)

## Quality Enhancement Checklist
1. **Resolution Verification**: Minimum longest edge `>= 2048px` (2K/4K Ultra-HD), 300 DPI metadata.
2. **Micro-Contrast & Edge Acutance**: Apply `CIUnsharpMask` (`radius: 1.4, intensity: 0.45`) on product hero surfaces (paddle carbon texture, metallic rim, grip perforations).
3. **Color Space & Compression**: Enforce `sRGB IEC61966-2.1` color profile and `1.0` Lossless compression factor.
4. **Smart Logo Contrast Shield**: Ensure local background behind the `11 SPORT` logo (`top-right`) is optically isolated via a 3-Pass Contrast Shield (Adaptive Radial Scrim + Contoured Halo + Directional Drop Shadow) so background elements never obscure the logo.
